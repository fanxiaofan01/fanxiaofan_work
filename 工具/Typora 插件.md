## 问答

- **我的 Typora 被支持吗？** Typora 的版本应该是 0.9.98（最后一个免费版本）≥。
- **如何修改插件配置？** 右键菜单 -> 少用插件 -> 偏好设置。**尊重所有用户的选择**。任何插件或功能都可以永久启用或禁用。
- **如何升级插件？** 右键菜单 - > 少用插件 - > 升级插件。
- **如何卸载插件？** 右键菜单 -> 少用插件 -> 偏好设置 -> 卸载插件。
- **如何开发插件？** 该项目遵循 **无构建时间原则**，因此无需安装任何开发环境。详情请参阅 [说明](https://github.com/obgnail/typora_plugin/blob/master/plugin/custom/README-en.md) 文档。
- **它支持 Mac 版的 Typora 吗？** 我没有 Mac 设备，所以没测试过。
- **还有其他问题吗？** 请向 [AI 维基](https://deepwiki.com/obgnail/typora_plugin) 咨询。

## 如何使用: Windows/Linux Platform



Visit [Video Installation Tutorial](https://github.com/obgnail/typora_plugin/issues/847)

1. [Download](https://github.com/obgnail/typora_plugin/releases/latest) 下载地址

2. 进入 Typora 安装路径，找到包含 的文件夹 A.`window.html`

   - 对于官方版本的 Typora，路径为 。`./resources/window.html`
   - 对于 Typora 的测试版，路径为。`./resources/app/window.html`

3. 把解压后的插件文件夹粘贴到文件夹 A 里。

   ![image-20260119203808369](https://cdn.jsdelivr.net/gh/fanxiaofan01/my_notes_imgs/img/20260119203808489.png)

4. 进入文件夹。`A/plugin/bin/`

   - Windows：右键点击文件。选择“使用 PowerShell 运行”。`installw_windows.ps1`
   - ![image-20260119203854589](https://cdn.jsdelivr.net/gh/fanxiaofan01/my_notes_imgs/img/20260119203854683.png)
   - Linux：以管理员身份运行。`install_linux.sh`

5. 验证：重启 Typora，右键点击主文本区域，如果看到那一栏，就一切正常。显示下图就证明安装成功了

   ![image-20260119203957662](https://cdn.jsdelivr.net/gh/fanxiaofan01/my_notes_imgs/img/20260119203957734.png)

## 插件使用说明



所有插件都提供四种使用方法：

- 键盘爱好者们：
  - `Ctrl+J` 调出插件列表（见插件）`toolbar`
  - 快捷键（参见插件）`hotkeys`
- 鼠标爱好者们：
  - 在主文本区域右键点击（见插件）`right_click_menu`
  - 快速按钮（见插件）`quickButton`

### window_tab：窗口标签栏



- `Switch tabs`： Ctrl + 滚轮，Ctrl + Shift + Tab，Ctrl + Tab，Ctrl + PgUp，Ctrl + PgDn
- `Close tab`： ctrl + w，中键
- `Open in new window`： ctrl + 点击标签页
- `Sort tabs`：拖放
- `Pop up menu options for tabs`：右键点击标签



### search_multi：多字段文件搜索器



功能：通过多种条件组合搜索，准确找到文件。

使用情况：

- 方法 1：右键菜单 - > 常用插件 - > 多字段文件搜索器
- 方法二：快捷键 `ctrl+shift+P`

使用示例：搜索语法类似于谷歌搜索语法，支持正则表达式。

| 输入                                                   | 检索文件                                                 |
| ------------------------------------------------------ | -------------------------------------------------------- |
| `pear`                                                 | 含有梨                                                   |
| `sour pear`                                            | 含有酸味和梨味                                           |
| `sour OR pear`                                         | 含有酸味或梨味                                           |
| `"sour pear"`                                          | 包含短语“酸梨”                                           |
| `sour pear -apple`                                     | 含有酸味和梨味，但不含苹果                               |
| `/\bsour\b/ pear mtime=2024-03-12`                     | 匹配正则表达式\bsour\b，包含梨，文件修改日期为 2024-03-12 |
| `frontmatter:development OR head=plugin OR strong:MIT` | YAML 前言包含开发或标题内容，插件或加粗文字包含 MIT      |
| `size>10kb (linenum>=1000 OR hasimage=true)`           | 文件大小超过 10KB，且文件至少有 1000 行或包含图片           |
| `thead:k8s h2:prometheus blockcode:"kubectl apply"`    | 表头包含 k8s，h2 包含 prometheus，代码块包含 kubectl 应用。   |



### collapse_paragraph: Chapter Folding



Function: Fold/expand all text under the section. Supported tags: h1~h6.

- `Fold/expand a single section`: ctrl + click
- `Fold/expand all sibling sections under the parent section`: ctrl + alt + click
- `Fold/expand all sibling sections`: ctrl + shift + alt + click



### collapse_list: List Folding



Function: Fold/expand unordered lists, ordered lists, task lists.

### collapse_table: Table Folding



Function: Fold/expand tables.

### md_padding：中英文本间隔器



功能：混合时添加中英、中文字与数字之间的空格。

快捷键：ctrl + shift + B



### slash_commands：斩击指令



功能：类似于 Notion 的斩击命令。

支持：

- 插入文本摘要（摘要）
- 插入组件
- 编辑风格
- 执行任意逻辑



### 模板器：文件模板器



功能：类似于 Obsidian 的文件模板功能，可以快速基于模板创建文件。

使用方式：右键菜单 - > 常用插件 - > 次要插件 - > 文件模板。



### resource_manager：资源管理



功能：资源管理，清理未使用的图像

使用情况：右键菜单 - > 少用插件 - > 资源管理

### fence_enhance：增强围栏



[![fence_enhance](https://github.com/obgnail/typora_plugin/raw/master/assets/fence_enhance.png)](https://github.com/obgnail/typora_plugin/blob/master/assets/fence_enhance.png)

### 目录：右侧生成大纲



功能：Typora 侧边栏无法同时显示 [文件] 和 [大纲]。为了解决这个问题，这个插件在右侧添加了一个 [大纲]。

使用情况：

- 方法 1：常用插件 -> 次要插件 -> 大纲
- 方法二：右键点击侧边栏的 [大纲] 按钮

### 指挥官：命令行环境



功能：类似于《全面指挥官》的命令行，是一种快速执行命令并减少交互的工具。

使用方式：右键菜单 - > 常用插件 - > 命令行环境

支撑壳体：

- `cmd/bash`：Windows 或 Linux 的默认终端
- `powershell`：Microsoft 傻孩子，: D
- `git bash` 确保安装并添加到环境变量中
- `wsl`： 确保安装并添加 WSL2 到环境变量中

内置环境变量：

- `$f`： 当前文件路径
- `$d`：当前文件目录
- `$m`： 已挂载根目录



### markmap：提供 Markmap 支持



使用情况：

- 方法 1：右键菜单 - > 少用插件 - > 标记映射
- 方法二：直接点击右下角的标记地图按钮



### 工具栏：多功能搜索器



函数：类似于 VSCode 的 ctrl + shift + p 函数

使用情况：

- 方法 1：右键菜单 -> 少用插件 -> 多功能搜索
- 方法二：快捷键 `ctrl + j`

支持搜索：

- `his`：最近打开的文件
- `plu`：插件
- `tab`：打开标签页
- `ops`：常见作
- `out`：文档大纲
- `mode`： 切换文件模式
- `theme`：暂时切换主题
- `func`：函数列表
- `all`：混合搜索（将所有混合物品一起搜索）

输入内容描述：

- 输入内容 = 搜索工具名称 + 空格 + 搜索内容
- 支持 、 和 可以自由组合（类似于谷歌的正负查询）`intersection queries` `difference queries`

示例：

- `his node learn` 查找最近打开的文件，标题包含 node 和 learn 关键字
- `plu multi -search`： 查找名称包含多关键词但不包含搜索关键词的插件
- `tab -messing`： 查找所有未包含 messing 关键字的打开标签页
- `his close -win -mark tab` 查找最近打开的文件，其标题包含关闭和制表关键词，但不包含胜利和标记关键词


### truncate_text：隐藏内容以提升大文件渲染性能



功能：Typora 中大文件的渲染性能非常差。使用这个插件可以暂时隐藏内容（只需隐藏显示，不修改文件），以提升渲染性能。它也可以用来防止偷看。

使用方式：右键菜单 - > 少用插件 - > 文本截断。

包含的功能如下：

- 隐藏前半部分：隐藏前半部分的文字，只保留最后 80 段。
- 重新显示：重新显示所有之前隐藏的文本。
- 根据当前可见光范围显示：根据当前可见光范围显示文本。

> 原则：通过将 DOM 元素的显示样式设置为零，元素被隐藏，使其不占据渲染树中的位置，且对隐藏元素的作不会导致其他元素的回流。
